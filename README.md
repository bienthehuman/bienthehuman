# Hey, I'm Bien 👋

**Full-stack software engineer. Backend enthusiast. Human behind the code.**

I build software, question decisions, and occasionally spend more time thinking about a problem than writing the code to solve it.

I'm a full-stack developer with a soft spot for backend development, databases, and understanding how things work under the hood.

Over the years, I've learned that being a good engineer isn't about knowing every technology or writing the most clever solution. It's about understanding problems, making thoughtful decisions, and building things that remain useful long after they're shipped.

Still learning. Still growing. Still figuring things out.

## `~/what-i-do`

Most of my work revolves around building applications, designing backend systems, working with databases, and figuring out how to make existing solutions better.

A few things I particularly enjoy:

- Backend architecture and database design
- Breaking down complicated problems
- Making systems simpler and easier to maintain
- Discussing ideas and challenging assumptions
- Sharing what I've learned with other developers

I work across the stack, but the backend is where I feel most at home.

## `~/how-i-think`

Some lessons I've picked up along the way:

**Understand the problem before solving it.**  
Writing code is often the easy part. Figuring out what actually needs to be built is another story.

**Simple doesn't mean easy.**  
Sometimes the best solution is the one that does less, but does it well.

**Good code is meant to be understood.**  
Not just by the person writing it, but by whoever comes after.

**There's always something to learn.**  
Experience gives you perspective, not all the answers.
